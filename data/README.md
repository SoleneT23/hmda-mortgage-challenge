# Données

Les données proviennent du challenge Kaggle consacré à la prédiction de
l'acceptation d'une demande de prêt immobilier à partir des données HMDA.

Les fichiers de données ne sont pas inclus dans ce dépôt. Après avoir téléchargé
les données depuis Kaggle, placer les fichiers suivants dans ce dossier :

- `train.csv` : données d'entraînement avec la cible `accepted` ;
- `test.csv` : données pour lesquelles les probabilités doivent être prédites ;
- `sample_submission.csv` : exemple du format de soumission attendu.
